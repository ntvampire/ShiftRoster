# График смен (ShiftRoster)

Кроссплатформенное приложение для автоматизации составления графиков смен, табельного учета, оперативного управления подменными работниками и выгрузки данных в Excel/1С.

Разработано на **.NET 8** и **Avalonia UI 11** с оформлением **FluentAvalonia (Microsoft WinUI 3 Dark Theme)**.

---

## Ключевые возможности

1. **Простой и доступный интерфейс:**
   - Отображение для пользователя: **«График смен»**;
   - Темная тема WinUI 3, снижающая усталость глаз;
   - Быстрое назначение смен в один клик через встроенную палитру (24ч сутки, 12ч день, 12ч ночь, 8ч, Выходной, Отпуск, Больничный).
2. **Строгий контроль круглосуточного поста (24 часа в сутки):**
   - Автоматическая проверка баланса: на круглосуточном посту в каждые сутки должно быть закрыто **ровно 24 часа — не больше и не меньше**;
   - Мгновенная цветовая индикация недоборов и переборов в нижней строке табеля и верхнем статусном баннере.
3. **Автозаполнение графиков:**
   - Предустановленный шаблон **«Сутки через трое (1/3)»** (4 смены, 24ч: 16ч день + 8ч ночь);
   - Предустановленный шаблон **«Сутки через двое (1/2)»** (3 смены, 24ч: 16ч день + 8ч ночь);
   - Предустановленный шаблон **«2 через 2 (2/2)»** (4 смены по 12ч: 12ч день + 12ч ночь).
4. **Управление подменными работниками и закрытие смен «на лету»:**
   - Длинные отсутствия: назначение подменного из резерва с переносом смен за весь период болезни («Б») или отпуска («О»);
   - Короткие отсутствия: подбор свободного коллеги поста для выхода в выходной с проверкой безопасности отдыха (исключение смен подряд);
   - Взаимный обмен сменами (смещение): обмен дежурствами между сотрудниками со 100% сохранением суточного баланса 24.0ч;
   - Неразрушающее наложение: базовый график не затирается, при отмене подмены всё автоматически возвращается на свои места.
5. **Производственный календарь РФ:**
   - Встроенный офлайн-календарь официальных нерабочих праздничных дней РФ;
   - Автоматическая синхронизация через интернет (xmlcalendar.ru);
   - Праздничные дни подсвечиваются и рассчитываются в двойной оплате, **без сокращения рабочих часов сменщиков** в предпраздничные дни.
6. **Выгрузка в Excel (без табельных номеров):**
   - **Лист 1: «Сводка для оператора 1С»** — крупная контрастная таблица с готовыми суммами отработанных, дневных, ночных и праздничных часов для мгновенного ручного внесения в документ 1С «Табель учета рабочего времени» без калькулятора;
   - **Лист 2: «Бланк Т-13»** — унифицированная форма учета рабочего времени, готовая к печати (А3/А4 альбомная).
7. **Автономность и надежность БД:**
   - База данных SQLite (`ShiftRoster.db`) хранится прямо в папке программы;
   - При старте создается 1 резервная копия, в папке `Backups/` сохраняются **строго 3 самые свежие копии** (старые автоматически удаляются).

## Запуск и сборка

### Обычный запуск в режиме разработки:
```bash
dotnet run
```

### Запуск встроенных тестов проверки требований ТЗ:
```bash
dotnet run -- --test
```

### Сборка автономных исполняемых файлов (Self-contained, без внешних зависимостей):

* **Windows x64:**
  ```powershell
  dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish\win-x64
  ```
* **Windows x86 (32-bit для Windows 7):**
  ```powershell
  dotnet publish -c Release -r win-x86 --self-contained true -p:PublishSingleFile=true -o publish\win-x86
  ```
* **Linux x64 (Astra Linux, РЕД ОС, Ubuntu):**
  ```bash
  dotnet publish -c Release -r linux-x64 --self-contained true -p:PublishSingleFile=true -o publish\linux-x64
  ```
