### Что нового в версии 1.0.10:

- **Безопасность автообновления:**
  - Внедрена строгая валидация URL загрузки обновлений: разрешены только доверенные адреса GitHub по HTTPS (`github.com`, `*.github.io`, `*.githubusercontent.com`).
  - Добавлена поддержка проверки контрольной суммы SHA-256 установочного пакета перед запуском.
  - Реализована санитизация имени скачиваемого файла с защитой от атак обхода путей (Path Traversal).
  - Для не-Windows систем (Linux/macOS) обеспечено безопасное открытие папки с архивом в файловом менеджере.

- **Надежность данных и целостность бэкапов SQLite:**
  - Резервное копирование переведено на штатный атомарный механизм SQLite `VACUUM INTO`, гарантирующий 100% целостность резервных копий при активном режиме WAL.
  - Добавлены вторичные индексы для таблиц `RosterCells`, `ShiftSchedules`, `AbsenceEvents`, `ShiftSubstitutions`, `ShiftSwaps` для мгновенных выборок данных без сканирования таблиц.
  - Все операции с базой данных переведены на единую фабрику соединений с фиксацией параметров WAL.

- **Защита от Formula Injection в Excel:**
  - Все текстовые поля (ФИО, должности, названия смен и примечания) автоматически санитизируются перед записью в отчеты Excel (экранирование ведущих символов `=`, `+`, `-`, `@`), предотвращая выполнение формул в MS Excel.

- **Устранение ошибок прав доступа:**
  - Запись аварийных логов сбоев перенаправлена строго в `%LOCALAPPDATA%\ShiftRoster\crash.log`, устраняя сбой прав доступа при установке программы в `C:\Program Files`.
